# AI_TRY_TCRT5000 — 第一版提交归档（V1 历史记录）

基于 STM32G0B1RBT6 + 8 路 TCRT5000 的文字识别器：扫描纸片数字 → 板载 ST Edge AI int8 推理
→ LED 数码管显示 + 串口输出各数字概率。本归档按开发阶段整理，供提交/存档使用。

## 目录

| 目录 | 内容 | 对应提交（主仓库） |
| --- | --- | --- |
| `AI_TCRT5000_ScanData/` | ① 扫描部分（已完成）：采集固件工程（TIM6 分时驱动 + ADC + 串口二进制帧） | a55f613（扫描阶段） |
| `Model_v1/` | ② 第一版模型：Python 训练/量化脚本 + C 模型（ST Edge AI 生成 int8）+ 模型产物与可行性报告 | ab5cc66 / ba4d883 |
| `MCU_Code/` | ③ 这一步单片机代码：当前完整固件（采集 + 板载推理 + 数码管显示，可构建） | 70b8246 |
| `Dataset/` | ④ 数据集：0~9 各 20 个扫描 CSV（共 200） | 81869d0 + 多次重扫 |
| `Python_Tools/` | ⑤ Python 工具：采集/渲染/训练/体检/量化/验证/显示 全套 10 个 | ca3a032 ~ 70b8246 |

## 关键结果

- PC 训练（0~9，200 样本，14/3/3 + Label Smoothing/weight decay）：5 划分测试均值 **81.3%±6.5%**；
- 板载部署：int8 量化（权重 22.4KB，零精度损失，stedgeai 验证 C 模型与参考一致 cos=1.0）；
- 固件资源：Flash 53.1% / RAM 12.0%（128KB / 144KB）。

## 说明

- 各目录为独立快照（含必要依赖），可单独使用；构建固件见 `MCU_Code/`；
- 后续计划：扩充数据集（每类 50+、多种字体/手写数字）提升模型泛化（见主仓库 README §6）。
