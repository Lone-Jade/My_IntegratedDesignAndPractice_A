# AI_TRY_TCRT5000 — 提交归档（V1 历史记录 + V2 最新结果）

基于 STM32G0B1RBT6 + 8 路 TCRT5000 的文字识别器：扫描纸片数字 → 板载 ST Edge AI int8 推理
→ LED 数码管显示 + 串口输出各数字概率。本归档按开发阶段整理，供提交/存档使用：
`Model_v1` 保留第一版（200 样本）历史，`Model_v2`、`MCU_Code`、`Python_Tools`、`Dataset`
均为**最新版本**（300 样本、固定划分、第二轮 int8 部署固件）。

## 关键结果

### 第一版（Model_v1，200 样本，随机 14/3/3）
- PC 训练（0~9，Label Smoothing/weight decay）：5 划分测试均值 **81.3%±6.5%**，多 seed 投票 83.3%；
- 部署模型测试 **76.67%**（30 样本）；int8 零精度损失；
- 固件资源：Flash 53.1% / RAM 12.0%。

### 最新版（Model_v2 / MCU_Code / Dataset，300 样本，固定划分 20/5/5）
- PC 训练（新旧字体混合固定划分）：5 seed 测试 **81.2%±1.0%**，多数投票 **88.0%**；
- 部署模型（seed 1042）测试 **82.0%**（50 样本）；int8 零精度损失（stedgeai validate：rmse=0、cos=1.0）；
- 新字体（域外）识别：旧模型 16%/52% → **94%**（字体域偏移已解决）；
- 固件：Flash 53.10% / RAM 12.04%，板载推理 + 数码管显示（置信度≥30% 保持 5s）。
